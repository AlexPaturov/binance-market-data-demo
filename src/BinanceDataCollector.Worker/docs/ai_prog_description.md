# Общие сведения

## Название проекта
Система сбора и хранения торговых данных (рабочее название)

## Цель проекта
Сбор и хранение данных для:
- Аналитики и исследования рынка
- Бэктестинга торговых стратегий
- Возможного предоставления API для других сервисов

## Ключевые пользователи/потребители данных
- Ты сам для анализа рынка и обучения моделей (LLM и трейдинг-алгоритмы)
- Возможное подключение внешних сервисов в будущем

# Данные и источники

## Какие биржевые сделки будут собираться
- Криптовалютные сделки (с Binance)
- В перспективе: фондовый рынок и другие биржи

## Какие данные по сделке нужны
- Время сделки
- Инструмент (пара)
- Цена
- Объем
- Тип сделки (покупка/продажа)
- Идентификатор биржи
- Дополнительно: ордербук, свечи, индикаторы (позже)

## Источники данных
- API Binance (REST + WebSocket)
- В будущем возможны другие API и провайдеры

## Конкретные API
- Binance Spot API (REST для исторических данных, WebSocket для стриминга)
- Возможное подключение Futures API позже

## Ограничения API
- REST API Binance: ограничение по запросам (обычно 1200 req/min, зависит от эндпоинта)
- WebSocket поток: до 1024 подписок на одном соединении

## Частота сбора данных
- В реальном времени через WebSocket
- Периодический запрос исторических данных для бэкапов

## Объем данных
- ~Много сделок в секунду для популярных пар
- Первоначально сбор по ограниченному списку инструментов

## История данных
- Да, нужен сбор исторических данных минимум за 1-2 года для бэктестинга
