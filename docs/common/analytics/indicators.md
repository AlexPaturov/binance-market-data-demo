# Индикаторы и фичи

Два независимых потребителя считают индикаторы по-разному, и это осознанно.

| Кто | Что считает | На чём | Куда пишет |
| :--- | :--- | :--- | :--- |
| **`FeatureCalculatorWorker`** | Фичи для ML | Минутные свечи, фиксированные периоды | `Ohlcv_Features` |
| **Страница `/Chart`** | Индикаторы для глаз | Свечи выбранного таймфрейма, настраиваемые периоды | никуда, считаются на лету |
| **`OrderBookCollectorWorker`** | Фичи стакана | Книга в памяти | `OrderBook_Features` |

Библиотека расчёта — [Skender.Stock.Indicators](https://dotnet.stockindicators.dev/), кроме CVD (считается прямо из тиков).

---

## Фичи для ML (`Ohlcv_Features`)

Считаются `FeatureCalculatorWorker` раз в 2 минуты по свечам со статусом `'new'`.

| Индикатор | Параметры | Минимум данных | Колонка |
|---|---|---|---|
| **RSI** | период 14 | ~26 свечей | `RSI_14` |
| **MACD** | 12 / 26 / 9 | 35 свечей | `MACD_Signal`, `MACD_Hist` |
| **CVD** | — | 1 минута тиков | `CVD` |
| **MA 2Y** | SMA(1 051 200) | ≈ 2 года минутных свечей | `MA_1051200` |
| **MA 200W** | SMA(2 016 000) | ≈ 3.8 года | `MA_201600` |

### RSI-14
Скорость и сила ценового движения, 0–100. Выше 70 — перекупленность, ниже 30 — перепроданность.

### MACD
Разница двух EMA. `MACD_Signal` — сигнальная линия (EMA9 от MACD), `MACD_Hist` — гистограмма (MACD минус сигнал). Пересечение — сигнал входа/выхода.

### CVD (Cumulative Volume Delta)
Накопленная разница объёма покупок и продаж. Считается из `Trades` по флагу `IsBuyerMaker`, а не из свечей — показывает реальное давление агрессоров. Больше нуля — доминируют покупатели.

### ⚠️ MA 2Y и MA 200W всегда `NULL`

Периоды заданы **в минутных барах**: 1 051 200 минут — это два года, 2 016 000 — почти четыре. До накопления такой истории обе колонки пусты, а окно ретенции (19–30 месяцев) до 200W не дотягивает вовсе.

Правильное решение — считать их на дневных свечах. Пока не сделано, см. `docs/TECH_DEBT.md`.

## Индикаторы на графике

Страница `/Chart` **не берёт** значения из `Ohlcv_Features`, а пересчитывает их из свечей выбранного таймфрейма (`ChartIndicatorService`).

Причина: RSI(14) по 15-минутным свечам — это другое число, а не среднее из минутных. Хранимые фичи посчитаны на минутках и для старших таймфреймов просто неверны.

- **RSI, MACD** — периоды настраиваются на странице.
- **MA** — обычные SMA/EMA с периодом **в барах текущего таймфрейма** (MA(200) на дневных = 200 дней). Вечно-пустые `MA_1051200`/`MA_201600` на графике не используются.
- **CVD** — берётся из `Ohlcv_Features` как значение на конец бара: ряд кумулятивный, поэтому суммировать его нельзя.

### Часовой пояс оси времени

Комбобокс под графиками выбирает зону, в которой читается ось времени и подписи курсора; выбор запоминается в `localStorage` (ключ `chart.timezone`), по умолчанию — UTC.

`lightweight-charts` рисует `UTCTimestamp` в UTC, поэтому зона применяется сдвигом отметок времени на смещение зоны для **каждого** момента отдельно (`Intl.DateTimeFormat` → `zoneOffsetMs`). Единое смещение на весь ряд разъехалось бы на переходе через летнее время: бары до перехода и после него живут в разных смещениях. Данные с сервера всегда приходят в Unix-мс UTC — сдвиг существует только на стороне отрисовки.

## Фичи стакана (`OrderBook_Features`)

Считаются `OrderBookCollectorWorker` из книги в памяти, раз в минуту, по 12 срезам (снимок раз в 5 секунд).

| Фича | Что показывает |
| :--- | :--- |
| **Imbalance** | Перевес bid/ask в топ-20 уровнях, от -1 до +1. Классический предиктор краткосрочного движения. |
| **Depth ±0.1 / 0.5 / 1%** | Ликвидность вблизи цены — «толщина» рынка на трёх горизонтах. |
| **Spread** (абс. и bps) | Стоимость мгновенного входа и выхода. |
| **Стенки** | Крупнейшая одиночная заявка с каждой стороны и её удалённость от цены в bps. |
| **UpdateCount** | Сколько раз книга обновилась за минуту — прокси нервозности рынка. |
| **SampleCount** | Сколько срезов усреднено. Меньше 12 — были разрывы связи, фичи менее надёжны. |

Подробности по полям — [`03_database.md`](../03_database.md), раздел 3.5.
