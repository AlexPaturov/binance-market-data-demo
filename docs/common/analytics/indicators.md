# Технические индикаторы

Индикаторы рассчитываются в `FeatureCalculatorWorker` и сохраняются в таблицу `Ohlcv_Features`.

Библиотека расчёта: [Skender.Stock.Indicators](https://dotnet.stockindicators.dev/) — исключение CVD (считается напрямую из тиков).

---

## Реализованные индикаторы

| Индикатор | Параметры | Таймфрейм | Источник данных | Минимум данных | Статус |
|---|---|---|---|---|---|
| **RSI** | Period = 14 | 1 мин | `Ohlcv_1min` | ~26 свечей (~30 мин) | ✅ Работает |
| **MACD** | Fast=12, Slow=26, Signal=9 | 1 мин | `Ohlcv_1min` | 35 свечей (~35 мин) | ✅ Работает |
| **CVD** | — | 1 мин | `Trades` (тики) | 1 минута тиков | ✅ Работает |
| **MA 2Y** | SMA(1 051 200) | 1 мин | `Ohlcv_1min` | 1 051 200 свечей ≈ 2 года | ⚠️ Всегда NULL (см. ниже) |
| **MA 200W** | SMA(2 016 000) | 1 мин | `Ohlcv_1min` | 2 016 000 свечей ≈ 3.8 года | ⚠️ Всегда NULL (см. ниже) |

---

## Описание индикаторов

### RSI-14 (Relative Strength Index)

Измеряет скорость и силу ценового движения. Значения от 0 до 100.

- **> 70** — перекупленность (потенциальный разворот вниз)
- **< 30** — перепроданность (потенциальный разворот вверх)
- **Колонка:** `RSI_14`

### MACD (Moving Average Convergence Divergence)

Трендовый осциллятор на основе разницы двух EMA.

- **MACD Line** = EMA(12) − EMA(26)
- **Signal Line** = EMA(9) от MACD Line
- **Histogram** = MACD Line − Signal Line (сохраняется в `MACD_Hist`)
- Пересечение MACD и Signal — сигнал входа/выхода
- **Колонки:** `MACD_Signal`, `MACD_Hist`

### CVD (Cumulative Volume Delta)

Накопленная разница между объёмом покупок и продаж внутри каждой минутной свечи. Показывает реальное давление покупателей/продавцов.

- **> 0** — доминируют покупатели
- **< 0** — доминируют продавцы
- Считается из таблицы `Trades` (поле `IsBuyerMaker`), а не из OHLCV
- **Колонка:** `CVD`

### MA 2Y / MA 200W (макро Moving Averages)

Долгосрочные скользящие средние для определения рыночного режима.

- **MA 2Y** — цена выше: бычий рынок; ниже: медвежий
- **MA 200W** — исторически Bitcoin никогда не закрывал неделю ниже этого уровня (макро-дно)

**Текущая проблема:** оба индикатора рассчитываются на 1-минутных свечах, из-за чего требуют 2–4 года данных для первого ненулевого значения. До тех пор колонки всегда `NULL`. Правильное решение — перевести расчёт на дневные свечи (`Ohlcv_1d`). См. `TECH_DEBT.md`.

- **Колонки:** `MA_1051200`, `MA_201600`

## Архитектура расчёта

```
Trades (тики)
    │
    ├─► GetCvdForOhlcvAsync ──────────────────────────► CVD в Ohlcv_Features
    │
Ohlcv_1min (свечи со статусом 'new')
    │
    ├─► ClaimNewKlinesForProcessingAsync  (BatchSize=100)
    ├─► GetWarmupKlinesAsync (WarmupPeriod=2 016 000 свечей)
    ├─► IndicatorService.CalculateAll
    │       ├─ RSI(14)
    │       ├─ MACD(12,26,9)
    │       ├─ SMA(1 051 200)  → MA_1051200
    │       └─ SMA(2 016 000)  → MA_201600
    └─► UpsertFeaturesAsync ──────────────────────────► Ohlcv_Features
```
