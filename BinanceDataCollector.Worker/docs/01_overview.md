# Документация: 01 - Обзор проекта

## 1. Назначение системы

**`BinanceDataCollector`** — это автономный, самовосстанавливающийся и отказоустойчивый программный комплекс, предназначенный для непрерывного сбора, хранения и предварительной обработки рыночных данных с криптовалютной биржи **Binance**.

Основная задача системы — формировать чистое, полное и готовое к анализу хранилище данных, которое может служить фундаментом для:
- Бэктестинга торговых стратегий.
- Расчета и хранения технических индикаторов.
- Подготовки наборов данных (datasets) для обучения моделей машинного обучения (ML/LLM).
- Визуализации рыночной активности.

## 2. Философия и ключевые принципы

Система спроектирована с учетом следующих принципов:

- **Автономность:** После первоначальной настройки система работает 24/7 без необходимости вмешательства человека.
- **Надежность:** Все компоненты спроектированы для автоматического перезапуска и восстановления после сбоев.
- **Целостность данных:** Встроенные механизмы аудита находят и заполняют любые пробелы в данных, которые могли возникнуть из-за простоев.
- **Производительность:** "Тяжелые" операции (массовая вставка, агрегация) вынесены на уровень базы данных для максимальной эффективности.
- **Автоматизация развертывания:** Обновления кода доставляются на сервер автоматически через CI/CD пайплайн.

## 3. Основной алгоритм работы (ETL-конвейер)

Система функционирует как непрерывный, многослойный конвейер данных (ETL), состоящий из следующих этапов:

1.  **Разведка (`Scanner`):** Система периодически сканирует рынок, чтобы определить список самых ликвидных и волатильных валютных пар.
2.  **Сбор (`Collector`):** Система в реальном времени подписывается на потоки сделок (тиков) для этих отобранных пар и сохраняет каждый тик в базу данных (**Слой 0: Сырые данные**).
3.  **Агрегация (`Aggregator`):** Сырые тиковые данные непрерывно агрегируются в стандартные минутные свечи (OHLCV), формируя **Слой 1: Агрегированные данные**.
4.  **Расчет признаков (`Feature Calculator`):** На основе свечей и тиков система рассчитывает массив технических индикаторов (RSI, MACD, CVD и др.), создавая **Слой 2: Данные для анализа (Признаки)**.
5.  **Аудит (`Auditor`):** Система регулярно проверяет целостность всех слоев данных и автоматически заполняет пробелы, используя исторические API биржи.

## 4. Технологический стек

- **Язык программирования:** C#
- **Платформа:** .NET 8
- **База данных:** PostgreSQL 16
- **Среда выполнения:** Docker / Docker Compose
- **CI/CD:** GitHub Actions (Self-hosted Runner)
- **Операционная система сервера:** Ubuntu Server 22.04 LTS
- **Библиотека для индикаторов:** `Skender.Stock.Indicators`
